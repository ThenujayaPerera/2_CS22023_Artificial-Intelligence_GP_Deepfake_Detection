ABOUT DEEPGUARD

Understanding what lies beneath.

AI-generated facial images are becoming increasingly realistic. DeepGuard AI is a student-developed project that investigates deepfake detection through image preprocessing and CNN-based classification.

◎

Face Preparation

Detects and prepares a face region before sending the image to the classification model.

◇

CNN Analysis

Uses the trained convolutional neural network to evaluate visual patterns in the prepared image.

▥

Clear Results

Presents the predicted class, confidence, fake probability and processed model input.
